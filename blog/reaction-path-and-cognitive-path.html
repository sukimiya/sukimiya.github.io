Reaction Path 与 Cognitive Path：具身智能的双路径认知架构

具身智能系统面临一个与传统 LLM 完全不同的问题：

机器人不仅需要思考，还必须及时行动。

如果所有传感器信息都先进入大模型，等待 LLM/VLM 完成推理，然后再决定机器人动作，那么整个系统不仅延迟高，而且很难保证实时性。

但如果机器人完全依赖预先训练好的 Policy 或规则进行快速反应，它又很难理解复杂的社会环境、临时目标和长期任务。

因此，一个更加合理的具身智能架构应该同时存在两条路径：

Reaction Path 与 Cognitive Path。

1. Reaction Path：快速反应路径

Reaction Path 负责：

低延迟、确定性较高、需要立即执行的行为。

典型任务包括：

  • 平衡控制
  • 避障
  • 碰撞保护
  • 抓取修正
  • 电机控制
  • 紧急停止
  • 已学习技能的快速执行

其基本结构可以表示为：

Sensors
   │
   ▼
Perception
   │
   ▼
Reaction Policy
   │
   ▼
Motor Controller
   │
   ▼
Actuator

这条路径不应该依赖大型 LLM。

它可能主要运行：

Control Policy
Small Neural Network
VLA Policy
State Machine
MPC
RL Policy
Safety Controller

时间尺度可能处于：

1~10 ms     Motor Control
10~100 ms   Perception / Motion

Reaction Path 的核心目标不是“理解整个世界”，而是：

在正确的时间做出足够正确的动作。

2. Cognitive Path：认知推理路径

Cognitive Path 处理另外一类问题：

当前到底应该做什么？

它负责：

Understanding
Reasoning
Planning
Goal Management
Social Understanding
Memory Retrieval
World Model
Long-horizon Decision

基本结构：

                 Context
                    │
                    ▼
                 VLM/LLM
                    │
              World Model
                    │
                 Memory
                    │
               Goal System
                    │
                 Planner
                    │
               Task / Skill

它的时间尺度可以明显更慢：

100 ms
1 second
数秒
甚至更长

因为 Cognitive Path 解决的不是电机下一毫秒应该输出多少力矩，而是：

为什么要做这件事？

3. 两条路径必须同时存在

真正关键的不是二选一。

而是：

                    Environment
                         │
                       Sensors
                         │
                ┌────────┴────────┐
                │                 │
                ▼                 ▼

          Reaction Path      Cognitive Path
                │                 │
          Fast Policy          Reasoning
                │              World Model
                │              Memory
                │              Planning
                │                 │
                └────────┬────────┘
                         │
                    Action Layer
                         │
                      Robot

Cognitive Path 可以改变 Reaction Path 的目标和约束。

但 Reaction Path 不应该等待 Cognitive Path 才运行。

4. 一个打麻将的例子

假设一个陪伴机器人正在陪四位老人打麻将。

上家打出一张八筒。

从纯游戏策略来看：

牌型满足胡牌条件
        ↓
       胡牌

Reaction Policy 很容易学会这种映射。

但是此时机器人同时观察到：

对家眼睛眯了一下
+
嘴角上扬
+
老人今天情绪很好

与此同时，机器人当前存在一个更高层 Goal：

陪老人开心，比赢牌更重要。

于是 Cognitive Path 可能推导：

当前可以胡牌
        │
        ▼
游戏收益：高
        │
        ▼
但当前 Social Goal：
老人娱乐体验 > 游戏胜率
        │
        ▼
暂时放弃胡牌

最终：

Cognitive Path
      │
      ▼
Temporary Goal

"不要最大化胜率，
最大化老人娱乐体验"

      │
      ▼
Reaction / Game Policy

于是机器人选择：

不胡。

这里体现了双路径架构真正重要的能力：

Reaction Path 负责“我会怎么做”，Cognitive Path 决定“现在为什么这么做”。

5. Cognitive Path 不应该直接控制每一个动作

例如 Cognitive Path 输出：

拿起桌上的杯子

它不应该继续计算：

肩关节 +1.2°
肘关节 -0.7°
手腕 +0.3°
……

正确结构应该是：

Cognitive Path

"把红色杯子递给用户"

        ↓

Task Planner

        ↓

Manipulation Skill

        ↓

Reaction / Motion Policy

        ↓

Motor Controller

这样大模型负责：

Intent / Goal / Constraint

而底层 Policy 负责：

Execution。

6. Temporary Goal 是两条路径之间的重要接口

机器人真正需要的不只是永久规则。

现实世界大量任务是：

临时目标。

例如：

今天陪老人玩，所以不要太认真赢。

这个杯子很珍贵，动作慢一点。

孩子正在睡觉，所有动作降低噪声。

用户今天赶时间，优先完成任务。

这里地面湿滑，降低移动速度。

这些信息不应该重新训练 Policy。

而应该进入：

Temporary Goal
+
Constraint
+
Priority

再动态影响 Reaction Path。

7. Reaction Path 仍然拥有最终安全约束

Cognitive Path 可以说：

赶快过去。

但 Reaction Path / Safety Layer 可以拒绝：

前方有人
速度过高
碰撞风险

因此：

Cognitive Goal
      │
      ▼
Action Proposal
      │
      ▼
Safety / Reaction Layer
      │
   ┌──┴──┐
   │     │
Accept Reject

LLM 不能绕过底层安全控制。

8. 最终架构

完整系统可以抽象为：

                    Sensors
                       │
            ┌──────────┴──────────┐
            │                     │
            ▼                     ▼

       Reaction Path         Cognitive Path

       Perception            VLM / LLM
       Fast Policy           World Model
       Motion Policy         Memory
       Safety                Goal System
            │                Planning
            │                     │
            └──────────┬──────────┘
                       │
                 Action Arbitration
                       │
                  Robot Control
                       │
                    Actuator

双路径架构的核心不是让机器人拥有两个“大脑”。

而是承认一个基本事实：

现实世界既需要毫秒级反应，也需要秒级甚至分钟级思考。

试图用一个模型同时解决两个时间尺度的问题，很可能既浪费算力，又降低可靠性。

因此真正灵活的具身智能应该同时拥有：

Reaction Path——快速、稳定、可预测。

以及：

Cognitive Path——理解、推理、规划、调整目标。

两者共同运行，才可能形成真正具有适应性的机器人行为系统。
