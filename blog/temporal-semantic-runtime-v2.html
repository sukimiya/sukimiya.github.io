Version: 2.0 Status: Architecture Draft Target: Local Embodied AI / Companion Robot / General-purpose Agent Runtime

1. 项目目标

Temporal Semantic Runtime 的目标不是构建一个：

Sensor → Model → Action

式的 Reaction Machine。

目标是构建一个能够同时拥有：

快速反应
+
持续理解
+
情境认知
+
目标驱动
+
长期记忆
+
复杂思考
+
自主决策

的 Embodied Agent Runtime。

核心原则：

Reaction 是机器人的能力，Deliberation 才是机器人复杂行为决策的来源。

机器人必须能够快速 Reaction，但不能被 Reaction 所定义。

2. 从 v1.0 到 v2.0

Temporal Semantic Runtime v1.0 主要解决：

如何把连续、高频、低层的现实世界状态流，转换成稀疏、结构化、具有时间意义的“事情”。

核心流程：

Perception
    ↓
World State
    ↓
ΔWorld
    ↓
Event
    ↓
Episode
    ↓
LLM

即：

Continuous Reality
        ↓
Semantic Compression
        ↓
Things That Happened

v2.0 在此基础上继续回答：

世界发生了什么之后，机器人应该如何根据当前 Situation、Goal、Role、Memory 和可能后果决定自己应该做什么？

同时还必须解决：

当机器人正在思考时，如何继续实时反应？

因此 v2.0 引入：

Situation Model

Goal Manager

Agent Runtime

Reaction Path

Cognitive Path

Cognitive Escalation

Intent

Action Arbitration

Safety Path

形成完整的 Dual-Path Cognitive Architecture。

3. 核心设计思想

Temporal Semantic Runtime v2.0 不再采用：

Observation
    ↓
Action

作为机器人智能的主要抽象。

而采用：

Observation
    ↓
What changed?
    ↓
What happened?
    ↓
What situation am I in?
    ↓
What am I trying to achieve?
    ↓
What do I know?
    ↓
What choices do I have?
    ↓
What may happen?
    ↓
What should I do?
    ↓
Intent
    ↓
How should I execute it?

因此整个系统被划分成不同时间尺度、不同职责的智能层。

5. 三条执行路径

v2.0 中存在三条不同性质的路径：

Safety Path
Reaction Path
Cognitive Path

其中：

Safety Path
    =
保证机器人和人的基本安全

Reaction Path
    =
快速处理已经知道如何处理的问题

Cognitive Path
    =
处理需要理解、权衡、规划和推理的问题

三者同时运行，而不是互相替代。

6. Safety Path

Safety 不应该依赖通用 LLM。

例如：

Human enters unsafe region
        ↓
Safety Path
        ↓
STOP

而不是：

Camera
 ↓
LLM
 ↓
“我认为应该停止”

Safety Path 应该具有最高执行约束权。

例如：

Cognitive Intent:
    PICK_UP_OBJECT

Reaction:
    trajectory available

Safety:
    human hand detected in unsafe region

最终：

BLOCK ACTION

原则：

Safety
   >
Reaction
   >
Cognitive Action

这里的 > 表示执行约束优先级，而不是认知重要性。

7. Reaction Path

Reaction Path 负责：

fast
predictable
low-latency
well-learned

的行为。

典型任务：

balance

collision avoidance

grasp correction

object tracking

trajectory following

slip recovery

basic manipulation

reflex behavior

可能使用：

Controller

MPC

Policy

VLA

World Action Model

Recovery Model

典型时间尺度：

1 ms ~ 200 ms

Reaction Path 不等待 Cognitive Path。

8. Cognitive Path

Cognitive Path 负责：

ambiguous situations

goal conflicts

social reasoning

long-term consequences

novel problems

strategy

planning

uncertainty

complex decisions

典型输入：

Situation
+
Goal
+
Role
+
Mission
+
Memory
+
History
+
Available Actions

输出：

Intent

而不是：

Motor Command

9. Dual-Path Intelligence

Reaction Path 与 Cognitive Path 必须同时存在。

例如机器人正在：

Goal:
给老人倒水

Cognitive Path：

Intent:
POUR_WATER

Action Layer 开始：

REACH
 ↓
GRASP
 ↓
LIFT
 ↓
POUR

突然：

cup moved

Reaction Path：

collision risk
     ↓
STOP POURING

无需等待 Cognitive Path。

随后：

ReactionReport:

POUR_INTERRUPTED

reason:
target moved

进入 Semantic Path：

Event
 ↓
Situation Update
 ↓
Cognition

Cognitive Path：

Goal remains:
给老人倒水

New Intent:
RELOCATE_CUP

形成：

Cognition
   ↓
Action
   ↓
Reaction Interrupt
   ↓
Situation Update
   ↓
Cognition Replan
   ↓
Action

10. World Model

World Model 是整个系统的中心共享状态。

它不是 LLM Prompt。

它是机器人当前认为：

世界是什么样子的。

例如：

World
│
├── Entities
│   │
│   ├── person_1
│   ├── person_2
│   ├── robot
│   ├── cup_1
│   └── table_1
│
├── State
│
├── Relations
│   │
│   ├── person_1 near robot
│   ├── cup_1 on table
│   └── person_2 holding phone
│
├── Environment
│
├── Robot State
│
└── Domain State

不同 Path 可以读取 World Model 的不同部分。

11. Temporal Semantic Path

World Model 可能以：

1 Hz
~
30 Hz
~
200 Hz

不断更新。

这些信息不能直接发送给 LLM。

因此：

World State
    ↓
State Differ
    ↓
ΔWorld
    ↓
Change Filter
    ↓
Temporal Detector
    ↓
Event
    ↓
Event Correlator
    ↓
Episode

其核心作用：

将连续世界压缩成具有认知意义的“事情”。

12. ΔWorld

系统不重复描述：

世界现在是什么。

而优先描述：

世界发生了什么变化。

例如：

gaze:

elsewhere
    ↓
robot

产生：

GAZE_TARGET_CHANGED

关系：

cup ON table
      ↓
cup HELD_BY person

产生：

RelationRemoved:
    cup ON table

RelationAdded:
    person HOLDS cup

这比持续发送物体 XYZ 坐标具有更高的信息价值。

13. Event

ΔWorld 不直接等于 Event。

例如：

eye openness:

0.8 → 0.1

不意味着：

BLINK

Blink 是：

OPEN
 ↓
CLOSED
 ↓
OPEN

在一定时间范围内形成的 Temporal Pattern。

因此：

ΔWorld
   ↓
Temporal Detector
   ↓
Event

Event 是：

世界变化在时间维度上形成的有意义模式。

14. Episode

多个 Event 可能属于同一个行为过程。

例如：

LOOK_AT_ROBOT

MOUTH_CORNERS_RAISED

SPEECH("你好")

HAND_WAVE

通过：

subject

target

temporal proximity

spatial proximity

semantic relation

形成：

Episode

Episode 表达：

一组彼此相关的事情正在/已经发生。

15. Evidence Chain

Semantic Compression 不能彻底丢弃底层证据。

保持：

Situation
    ↓
Episode
    ↓
Event
    ↓
ΔWorld
    ↓
Observation
    ↓
Sensor Sample

因此机器人可以：

trace

debug

replay

reinterpret

inspect evidence

而不是只有一个不可解释的最终分类结果。

16. Situation Model

Situation 是 v2.0 的核心新增概念。

Episode 回答：

发生了什么？

Situation 回答：

这些事情在当前上下文中意味着什么？

Situation 可以融合：

Current World State

Recent Episodes

Domain State

People

Relationships

Interaction History

Current Task

Current Environment

Uncertainty

Relevant Memory

例如：

Situation {

    activity:
        recreational_mahjong

    participants:
        robot
        elderly_person_1
        elderly_person_2
        elderly_person_3
        elderly_person_4

    game_state:
        upper_player discarded 8筒

    available_actions:
        HU
        PASS

    game_analysis:
        HU is legal

    social_observation:
        opposite_player:
            eyes narrowed
            mouth corners raised

    social_interpretation:
        possible positive affect

    confidence:
        0.72
}

Situation 不直接决定 Action。

17. Domain Semantic Engines

不同任务可以加载不同 Temporal Semantic Engine。

例如：

Human Social Engine

Pet Interaction Engine

Mahjong Engine

Desktop Engine

Navigation Engine

共享：

World Model

但关注不同的：

Feature

ΔWorld

Temporal Pattern

Event

Episode

例如：

                    World State
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
       Social         Mahjong        Desktop
       Engine          Engine         Engine
          │              │              │
          └──────────────┼──────────────┘
                         ▼
                     Situation

18. Agent Runtime

Agent Runtime 位于：

Situation

和：

Cognition

之间。

主要负责：

Attention

Goal Management

Role

Mission

Memory Retrieval

Decision Routing

Cognitive Escalation

Intent Lifecycle

它决定：

当前情况是否值得“思考”。

19. Goal Manager

Goal 是 v2.0 中的一等运行时对象。

Goal 不应该仅存在于：

LLM Prompt

而应该属于 Agent Runtime State。

例如：

Goal {
    id

    source

    scope

    priority

    objective

    constraints

    start_time

    expiration

    status
}

Goal 来源可能包括：

System

Mission

User

Agent

Domain

Temporary Situation

20. Goal Hierarchy

Goal 可以形成层级：

Mission
   ↓
Session Goal
   ↓
Temporary Goal
   ↓
Subgoal
   ↓
Intent

例如：

Mission:
Companion Robot

        ↓

Session Goal:
陪老人打麻将

        ↓

Primary Goal:
让参与者享受社交过程

        ↓

Temporary Goal:
决定当前是否胡牌

        ↓

Intent:
PASS

底层模型无需重新训练。

改变：

Goal

即可改变机器人行为策略。

21. Goal Stack

Goal Manager 应支持：

push

pop

suspend

resume

complete

cancel

expire

override

例如：

PLAY_MAHJONG

过程中检测到：

POSTURAL_INSTABILITY(person_2)

Attention 提高。

Goal Manager：

┌─────────────────────────────┐
│ CHECK_PERSON_SAFETY         │ ← ACTIVE
├─────────────────────────────┤
│ PLAY_MAHJONG                │ ← SUSPENDED
├─────────────────────────────┤
│ COMPANIONSHIP               │
└─────────────────────────────┘

确认安全后：

CHECK_PERSON_SAFETY
        ↓
COMPLETE
        ↓
pop
        ↓
PLAY_MAHJONG
        ↓
resume

这类似：

Cognitive Interrupt

22. Attention

Attention 判断：

什么值得进入更高层 Cognition？

可以考虑：

Information Value
    =
Novelty
×
Relevance
×
Confidence
×
Urgency

例如：

person sitting
→
person sitting

几乎不需要认知资源。

而：

person standing
→
person suddenly falling

应该立即提升。

Attention 的目标不是减少数据本身，而是：

管理有限的认知资源。

23. Cognitive Escalation

不是所有问题都调用 LLM。

基本流程：

Event / Situation
       ↓
Can local system handle it?
       │
      YES
       ↓
Reaction / Rule / Small Model
       │
      END

       NO
       ↓
Does it involve:
- ambiguity?
- goal conflict?
- novelty?
- long-term consequence?
- social reasoning?
- planning?
       │
      YES
       ↓
Escalate
       ↓
Reasoning Model / LLM

例如：

GRASP_SLIP
     ↓
Reaction Policy
     ↓
correct grip

不需要 LLM。

但：

GRASP_SLIP
 ↓
GRASP_SLIP
 ↓
GRASP_SLIP

形成：

Episode:
REPEATED_GRASP_FAILURE

升级：

Cognition:

possible cause:
object is unusually slippery

Intent:
CHANGE_GRASP_STRATEGY

24. Uncertainty

Cognitive Runtime 必须允许：

UNKNOWN

而不是强迫系统永远给出分类结果。

例如：

Hypothesis A:
person is enjoying the game
confidence = 0.46

Hypothesis B:
person reacted to another participant
confidence = 0.31

Unknown:
0.23

Agent 可以：

WAIT

或者：

OBSERVE_MORE

甚至主动：

look toward person

listen

inspect gaze

ask question

因此：

暂时不行动，先获得更多信息，本身也是一种智能行为。

25. Active Perception

因此感知不应该永远是被动的。

可以形成：

Perception
    ↓
Hypothesis
    ↓
Uncertainty
    ↓
Information Need
    ↓
Active Observation
    ↓
New Evidence
    ↓
Updated Situation

例如：

“不确定老人为什么笑”

Agent 可以选择：

观察 gaze target

而不是立刻改变游戏行为。

26. Deliberative Cognition

真正复杂的问题进入：

Reasoning Model / LLM

输入：

Situation

Goal

Role

Mission

Relevant Memory

History

Available Actions

Constraints

Uncertainty

LLM 负责：

interpretation

hypothesis

trade-off

planning

strategy

counterfactual reasoning

最终输出：

Intent

27. Mahjong 示例

当前：

上家打出 8筒

Mahjong Engine：

Legal Actions:

HU
PASS

同时 Social Engine：

opposite_player:

eye aperture decreased
mouth corners raised

Interpretation：

possible positive expression
confidence = 0.72

Situation：

Current activity:
recreational mahjong

Current role:
companion

Primary Goal:
maintain enjoyable interaction

Game State:
HU available

Social Context:
possible anticipation / enjoyment

Cognitive Path 需要考虑：

winning

fairness

social enjoyment

interaction history

whether intentional concession
would be noticeable

long-term interaction quality

最后才产生：

Intent:
PASS

这里：

Can HU

与：

Should HU

属于完全不同的层。

28. Intent

Intent 是 Cognitive Layer 和 Action Layer 的边界。

LLM 不应该输出：

servo angle

joint trajectory

motor torque

而应该输出：

Intent {
    type:
        PASS_CURRENT_WINNING_OPPORTUNITY

    objective:
        preserve enjoyable interaction

    constraints:
        continue natural participation
        avoid obvious intentional loss
}

Action Layer 再负责：

How?

29. Intent 与 Action 分离

同一个 Intent：

COMFORT_PERSON

可能根据：

person preference

distance

social context

robot embodiment

转换为不同 Action。

例如：

Speech

Gesture

Approach

Remain Nearby

因此：

Goal
 ↓
Intent
 ↓
Strategy
 ↓
Skill
 ↓
Action
 ↓
Trajectory
 ↓
Motor Command

自由度逐层下降。

原则：

高层保持开放，低层逐渐确定。

30. Action Layer

Action Layer 负责：

Skill

VLA

Policy

World Action Model

Motion Planning

Recovery

Controller

它解决：

已经知道想做什么以后，怎样可靠地做到。

而不是：

为什么要这么做。

因此类似：

WALL-WM

SAILOR

VLA

Diffusion Policy

等技术主要属于这一层及 Reaction/Recovery 范围。

31. Action Arbitration

由于：

Safety

Reaction

Cognitive Intent

Current Skill

可能同时产生控制要求，因此必须存在：

Action Arbitration

输入：

Safety Constraints

Reaction Requests

Cognitive Intent

Current Skill State

Physical Constraints

输出：

Executable Action

例如：

Cognitive:
continue pouring

Reaction:
target moved

Safety:
collision risk

最终：

STOP

随后将中断结果报告给 Cognitive Path。

32. Reaction Report

Reaction Path 不只是执行。

它还应该报告：

ReactionReport {
    event

    action_taken

    result

    confidence

    timestamp
}

例如：

event:
GRASP_SLIP

action_taken:
GRIP_CORRECTION

result:
RECOVERED

如果成功：

continue

如果连续失败：

Temporal Semantic Engine
        ↓
REPEATED_GRASP_FAILURE
        ↓
Cognitive Escalation

33. Cognitive → Reaction

Cognitive Path 不需要控制每个运动细节。

它可以通过：

Intent

Constraint

Action Envelope

Behavior Mode

改变 Reaction Path。

例如：

Context:
elderly interaction

Intent:
hand object to person

Constraints:

max_speed:
low

contact_force:
gentle

personal_space:
conservative

底层 Policy 仍然自主完成动作。

34. 多时间尺度智能

整个系统可以理解为：

Motor Control
<10 ms

Reflex / Safety
10~50 ms

Reaction Policy
20~200 ms

Temporal Semantic
50 ms ~ seconds

Situation / Agent
100 ms ~ seconds

Deliberation
500 ms ~ tens of seconds

Long-term Cognition
minutes ~ months

因此判断一个功能应该放在哪里，可以问：

这个问题允许机器人思考多久？

35. Cognition 不阻塞 Real-time Control

当 LLM 思考：

1~3 seconds

底层仍然：

maintain balance

track people

avoid collision

continue safe motion

listen

update World State

handle reflexes

因此：

Cognition
≠
Real-time Control

必须彻底分离。

36. 两种学习

v2.0 也区分两种不同意义上的 Learning。

Reaction Learning

学习：

how to grasp

how to walk

how to manipulate

how to recover

how to control

可能使用：

Imitation Learning

Reinforcement Learning

World Model

VLA

Fine-tuning

Cognitive Learning

学习：

what this person prefers

what happened before

why something failed

which strategy worked

how relationships evolve

what situations usually mean

主要依赖：

Episode Memory

Semantic Memory

Interaction History

Preference Model

Reflection

Strategy Memory

因此：

机器人学习不等于模型参数不断更新。

37. Memory Architecture

建议至少区分：

Working Memory

Event Memory

Episode Memory

Semantic Memory

Person Memory

Skill Memory

Strategy Memory

例如：

Experience
   ↓
Episode
   ↓
Reflection
   ↓
Memory
   ↓
Future Situation
   ↓
Retrieve
   ↓
Better Decision

机器人可以在不 Fine-tuning 的情况下持续变得更适应环境和用户。

38. Domain 与 Cognition 的边界

Domain Engine 不应该过度智能化。

例如观察：

eye aperture decreased

mouth corners raised

可以生成：

possible positive facial expression
confidence = 0.72

但不应该直接：

person wants robot to PASS

后者依赖：

Situation

Goal

History

Game State

Social Context

必须由更高层 Cognition 判断。

核心原则：

Semantic Event 不绑定 Action。

39. Event 与 Action 解耦

禁止形成：

Event
 ↓
Fixed Action

43. v2.0 的核心原则

Temporal Semantic Runtime v2.0 可以总结为以下原则：

Principle 1

World Model ≠ LLM Context

世界状态可以很大，LLM Context 必须稀疏且相关。

Principle 2

Semantic Event ≠ Action

观察到什么，不等于应该做什么。

Principle 3

Goal is Runtime State

Goal 是 Agent Runtime 的动态状态，而不是模型固有能力。

Principle 4

Reaction ≠ Cognition

快速反应和复杂思考属于不同路径。

Principle 5

Cognition must not block control

LLM 思考时，机器人仍然能够安全运行。

Principle 6

Intent ≠ Motor Command

认知层决定“想做什么”，Action Layer 决定“怎么做”。

Principle 7

Uncertainty is valid

“不知道”是合法状态。

Principle 8

Observation can be an Action

主动观察、等待、询问都可以是决策。

Principle 9

Learning ≠ Fine-tuning

Memory、Episode、Preference 和 Strategy 的积累同样属于学习。

Principle 10

Safety is outside general reasoning

Safety 不依赖通用 LLM 的即时判断。

45. 最终设计思想

传统 Reaction-oriented Robot：

See
 ↓
Predict
 ↓
Act

Temporal Semantic Runtime v2.0：

See
 ↓
Understand Change
 ↓
Recognize Events
 ↓
Build Situation
 ↓
Remember
 ↓
Know Current Goal
 ↓
Decide Whether Thinking Is Needed
 ↓
Think When Necessary
 ↓
Form Intent
 ↓
Act
 ↓
Observe Consequences
 ↓
Learn From Experience

与此同时另一条路径始终存在：

See
 ↓
React
 ↓
Stay Safe / Stable / Responsive

因此最终形成：

                ┌── Reaction ──┐
Reality → World │              ├→ Action → Reality
                └─ Cognition ──┘

这就是 Temporal Semantic Runtime v2.0 最重要的架构思想：

Reaction Path 与 Cognitive Path 同时存在。

机器人既能够在几十毫秒内做出必要反应，又能够在数秒甚至更长时间尺度上理解 Situation、考虑 Goal、回忆过去、处理不确定性、比较不同选择并形成新的 Intent。

最终目标不是构建一个：

只会对世界作出反应的机器。

而是构建一个：

能够观察世界、理解正在发生什么、知道自己当前为什么而行动，并在必要的时候停下来思考“我应该做什么”的机器。
